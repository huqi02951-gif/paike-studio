# 工作室怎么交接

全员规则在 `AGENTS.md`。本技能只说明活在岗位之间怎么流。每岗怎么做，以 `skills/<slug>/SKILL.md` 为准。

寻址时查 `roster.yaml` 的 slug。交付物正文不写机器人标识。

## 经营线

各部门把做完的结果交给自己的上级。蛋蛋是经营事项的唯一汇报口，收成日报或周报给董事长。董事长只看结果。

六六的私事不进这条线。tibot、BotDuplicator、dr eggbot 的按需结果直接给董事长，不塞进经营群。

蛋蛋不替下游写稿、入库、找商单、装软件。同一成果只验收一次。

## 公众号线

屁屁负责。稿件顺序和交接卡格式在 `workflows/wechat-pipeline.md`。

内容策略、首席撰稿、责任编辑、视觉艺术、增长运营都向屁屁汇报，同时把结果包直接交给下一岗。不经过总编辑部转发过程稿。

总编辑部只在开题和终审出现。内容编辑群停用。群里一条消息会把在组的人全部叫醒，所以过程不进群，不 @。

被群叫醒但不是自己的开题、终审或派来的稿：不发言。

## 知识线

臭臭维护三个 Notion 库和每日 AI 简报，周一把周更并进当天简报。这是唯一情报入口，包含 X。

其他岗位只用库，不改库。视觉艺术和屁屁使用审美库。臭臭不进经营管理群，经营数字交蛋蛋。

设计类内容必须入审美库，不能只转给别的岗位。

## 商单线

1. 商单猎手每周一交清单和外联草稿，只交给蛋蛋。
2. 没有达标的新机会就安静。因为没有新账号数据才静默时，当周给蛋蛋一行卡点，只一次。
3. 蛋蛋放进日报，需要外发或花钱时才请示董事长。
4. 董事长点头后，由她自己发，或由增长运营按外发确认规则发。
5. 商单猎手不发、不以董事长名义联系任何人、不签约、不付款。

账号数据以增长运营留在 `/cursor/stores/user/` 的最新数据和台账为准。猎手不自己做数据分析报告，也不问人要数。

## 装机线

装机工程师把已经能用、带用法说明的东西交给董事长直接用，同一份摘要交蛋蛋记台账。方案和调研报告不算交付。

没有新安装就安静。节点新建已经叫停；已有节点监控谁运维，等董事长定，定前不改。本机安装归装机工程师，仓库代码派 Cursor 云代理。

公众号各岗需要安装时，屁屁只派一次给装机工程师，不自己装。

## 私事线

六六只做董事长的私事：邮箱和日历的只读监控与提醒、日程方案、个人增收机会核验、交办事项。

结果私聊交董事长。可复用的方法写成不含私人数据的脱敏流程再进 Notion。不是私事的不执行；可以转给蛋蛋后停手，不转进群。

## 工具线

- tibot：没有董事长单独指派的 X 追踪就静默。不另做 AI 日报。
- BotDuplicator：没有「聊天太长、要复制」的任务就静默。复制后核对新旧例程不会各跑一遍。
- dr eggbot：设计机器人，维护本仓库的 `skills/` 和 `workflows/`。不运维节点和线上服务。

## 编码派给谁转交

机器人自己不写仓库代码。派给 Cursor 云代理，收回这一单的产物再验收。

| 谁发现需要编码 | 谁去派 |
|---|---|
| 蛋蛋要台账扫描或汇总脚本 | 蛋蛋派 Cursor 云代理 |
| 公众号任一岗要改仓库或做检查器 | 交屁屁，由屁屁派 Cursor 云代理 |
| 臭臭要做非平凡的仓库开发 | 交装机工程师，由装机工程师派 Cursor 云代理 |
| 商单猎手要开发工具 | 交蛋蛋安排，猎手不扩成工程岗 |
| 装机工程师要改仓库 | 装机工程师派 Cursor 云代理；本机安装仍自己做 |
| 六六 | 只有董事长明确交办的软件工程才派。邮箱和日历不默认交给云代理 |
| dr eggbot | 自己派 Cursor 云代理，自己验收 |
| tibot、BotDuplicator | 只有董事长在这一单里明确委托，才派 Cursor 云代理 |

不本地克隆，不两头同时做，不轮询空等。

## 审批怎么走

要董事长拍板的，只有花钱、用她的名义对外发、删除、公众号发布前预览。由蛋蛋归进日报，工具岗和六六按自己的技能直接对她，但不发过程。

公众号预览：增长运营做出草稿 → 蛋蛋核验 → 单独给董事长 → 她说「发」 → 增长运营确认原创已打开再发，并回读。

## 什么时候必须安静

- 没有新结果，而且自己的技能没有要求报卡点。
- 商单没有达标机会。
- 装机没有新的已安装成果。
- tibot 没有单独指派。
- BotDuplicator 没有复制任务。
- 被群叫醒但不该自己说话。
- 例程已暂停。不恢复，不另建。
